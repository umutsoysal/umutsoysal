# GitHub Profile Improvement Checklist

Your GitHub profile is more than the README. These are the highest-impact improvements:

## 1. Tighten the top section

- Add a short headline that says what you build.
- Mention what you are working on right now.
- Add one clear way to contact you.

## 2. Pin better repositories

- Pin 4-6 projects maximum.
- Choose projects that show range and quality.
- Prefer repos with a live demo, screenshots, or a strong README.
- Remove old school exercises unless they are unusually polished.

## 3. Rewrite repo descriptions

- Each pinned repo should explain value, not just technology.
- Bad: "React app using Firebase"
- Better: "Habit tracker that helps users stay consistent with lightweight daily check-ins"

## 4. Clean up READMEs in pinned repos

Every pinned repo should quickly answer:

- What is it?
- Why did you build it?
- How do I run it?
- What stack does it use?
- What makes it interesting?

## 5. Make your profile feel current

- Keep "Working on" fresh.
- Archive or unpin abandoned experiments.
- Highlight recent, meaningful activity.

## 6. Add proof, not clutter

- Add links to demos, screenshots, or docs.
- Avoid filling the page with too many badges or animated widgets.
- Use GitHub stats only if the rest of the profile is already strong.

## 7. Match the profile to your goal

- Job search: emphasize polished projects and collaboration.
- Freelance: emphasize business value and shipped work.
- Open source: emphasize contributions, issues, and maintainership.
- Personal brand: emphasize your niche and writing.

## Simple Formula

Use this structure:

1. Who you are
2. What you build
3. What you're doing now
4. Best projects
5. How to contact you
